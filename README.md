# Revenue Casebook · Danny Deepak

Before I spend a rupee, I find where the last one leaked.

Live: https://dannygrowthmarketing.github.io/revenue-casebook/

Seven businesses traced from first search to the till: TONI&GUY Bangalore, MR Jewels, Elites Dental Care, Gold Coins Club & Resort, Foremost Public Adjusters, EveryWatch, Swift Restoration.

Static HTML, no build step on the server. Charts are hand-rolled SVG. Photos: client websites, or Unsplash stock where marked illustrative on the page.

## New: Systems and live demo (Nov 2026)

- [Systems: connecting the dots](https://dannygrowthmarketing.github.io/revenue-casebook/systems.html): nine data sources, one database, one dashboard, and what matching them revealed.
- [Live demo dashboard](https://dannygrowthmarketing.github.io/revenue-casebook/demo/resort-dashboard/index.html#/monthly): the resort dashboard on made-up data. Built with React and Supabase; the demo answers every data call from a local sample file, so no client data is published.
