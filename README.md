# Revenue Casebook · Danny Deepak

Before I spend a rupee, I find where the last one leaked.

Live: https://dannygrowthmarketing.github.io/revenue-casebook/

Seven businesses traced from first search to the till: TONI&GUY Bangalore, MR Jewels, Elites Dental Care, Gold Coins Club & Resort, Foremost Public Adjusters, EveryWatch, Swift Restoration.

Static HTML, no build step on the server. Charts are hand-rolled SVG. Photos: client websites, or Unsplash stock where marked illustrative on the page.

## Design system (Oct 2026 redesign)

- One shared stylesheet and script: `assets/cb.css`, `assets/cb.js`. Black, paper and one champagne accent.
- Type: Bodoni Moda for the voice, Hanken Grotesk for data, IBM Plex Mono for sources and labels.
- Every case reads in five chapters: The business → The diagnosis → The work → The proof → What comes next, with a 60-second summary at the top and a chapter rail.
- Each case keeps its own hero identity inside the shared system.
- The homepage before/after board is generated from each case's results table; the FAQ carries FAQPage schema.
