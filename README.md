# Revenue Leak Casebook — Daniel Deepak

Live: https://dannygrowthmarketing.github.io/revenue-casebook/

A consulting portfolio built around one question per business: **where was revenue leaking between the first search and the till, how was it found, and what changed?**

| Page | What it is |
|---|---|
| `index.html` | Positioning, filterable case index, cross-case leak matrix, method, evidence standard |
| `toni-and-guy.html` | 16-salon network, Bengaluru · grade A |
| `mr-jewels.html` | Jewellery D2C e-commerce · grade A |
| `elites-dental.html` | Dental clinic · grade B · active |
| `resort.html` | Resort & events venue (anonymised, active) · grade D |
| `foremost-pa.html` | US public adjuster lead-gen · grade B |
| `everywatch.html` | Marketplace, in-house role · grade C, includes an audit of earlier ROAS claims |
| `swift-restoration.html` | US emergency restoration · diagnostic |
| `leaks.html` | Eight recurring leaks with evidence |
| `outreach.html` | Outside-in leak scan + outreach-note drafter |
| `llms.txt`, `cases.json` | Machine-readable summaries for AI tools |

Every figure is labelled **Measured**, **Calculated** (formula shown), **Estimate**, or **Data unavailable**.

Built as static HTML; no build step needed to host. Source and build script live in the private working copy.
